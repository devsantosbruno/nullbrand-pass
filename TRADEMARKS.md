# Trademark policy

"nullbrand" is the name of this project. The code is MIT-licensed (see [LICENSE](LICENSE)); the license does not grant rights to the name or any logo. The name is currently unregistered (see [docs/trademark-check.md](docs/trademark-check.md)).

## You may, without asking

- Say your software is **compatible with**, **based on** or **a fork of** nullbrand, in plain text.
- Use the name to refer to the project accurately: in articles, packages, forks' README files, bug reports.
- Redistribute unmodified releases under the name `nullbrand`.

## Forks and modified versions

If you distribute a modified version, please:

- **Use a different name** for the package, binary and any download page. Do not use `nullbrand`, or names that are confusingly similar, as the name of your product.
- **Do not reuse the logo or icon** (when one exists).
- **State clearly** that it is a fork, for example "X, a fork of nullbrand", and that it is not the official project.
- **Keep the MIT notice** and your own security-reporting channel: reports about your fork must not go to this project's channel.

## Not allowed

- Presenting a fork or unrelated product as the official nullbrand, or as endorsed by it.
- Using the name in a domain, download page or package name in a way that could make users believe it is the official release.
- Signing or distributing builds in a way that presents them as the official app.

## Third-party names

nullbrand is not affiliated with, endorsed by or sponsored by any other password manager. It names no third-party product: files are recognised by their structure.
